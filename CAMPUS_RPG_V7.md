# Campus RPG V7 — Premium Virtual Campus

V7 keeps Admission V2 untouched and upgrades the world presentation.

- Admission is a reception lobby.
- Document Check is a registry document office.
- Screening is a registrar operations floor.
- SAC is a committee boardroom.
- IA is an interview room.
- Prerequisite is a classroom.
- Offer & Acceptance is a consultation lounge.
- Orientation is a seminar hall with cohort seating and a presentation screen.
- IT / Library / Moodle is a three-counter Student Services Centre.
- Handover is an Academic Office.
- Larger sprites, glass-wall accents, room shadows, ambient lighting, stronger depth and cinematic camera focus.
- Students visibly sit while waiting for Orientation.
- Orientation screen changes waiting → live → completed → next cohort.
- V6 slower walking, stable avatars and hybrid individual/cohort workflow remain.

Foundation: Phaser 3 (MIT) and the same open/free visual asset provenance documented in V5/V6.
