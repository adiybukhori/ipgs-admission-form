System Guide

Quick tutorial for daily use of the IPGS Admission Command Center.

LIVE V2 GUIDE

Quick start

Recommended daily routine
1
Open Dashboard
Start with the Action Center. It shows where applications are waiting and which stage needs attention.
2
Open Applications
Search by applicant name, reference number, ID/Passport, email or programme. Use intake, programme and stage filters to narrow the list.
3
Review one applicant
Click Open. Use Overview, Documents, Screening, SAC / Assessment, Offer & Acceptance and Activity tabs.
4
Monitor the current route
Follow the progress tracker from Application to Documents, Screening, SAC, IA/PREREQ, Offer and Accepted.
5
Use Reports
Review the funnel and distributions. Export the filtered Applications list to CSV when required.

Admission journey

V2 process reference
Application Received→ Document Review→ Screening→ SAC→ IA / PREREQ if required→ Eligible for Offer→ Offer Issued→ Accepted
Direct Entry: after SAC endorsement, a qualified Direct Entry case can bypass IA / Prerequisite and proceed towards offer eligibility.

How to use each module

What each screen is for

Dashboard

Use KPI cards, Action Center, programme distribution, intake distribution and the workflow funnel to identify bottlenecks quickly.

Applications

Search, filter, open an applicant, view the Drive folder / Admission Form PDF and export the current filtered result to CSV.

Applicant Drawer

Use Overview, Documents, Screening, SAC / Assessment, Offer & Acceptance and Activity as the applicant's single portal view.

SAC Monitoring

Review SAC sessions, candidate load and decision progress to identify pending candidates or decisions.

IA / PREREQ

Track assessment route, status, submission, interview, result and latest update for cases routed by SAC.

Reports

Use for management reporting: workflow funnel, programme, intake and referral-source distribution.

Troubleshooting & good practice

Use these checks first
  • If numbers look outdated, click Refresh in the top-right corner.
  • If an applicant cannot be found, clear all filters and search using the reference number or ID/Passport.
  • Open Drive folders and PDFs from the applicant drawer instead of manually browsing the master Drive structure.
  • Use the application reference number as the primary identifier when discussing a case internally.
  • Do not treat a screening recommendation as a final SAC decision.
  • For IA / PREREQ candidates, confirm the assessment result before moving towards Offer.
  • Offer generation should only happen after the case is eligible for offer.
  • The admission process in this portal ends at ACCEPTED; activation, orientation and academic handover belong to the subsequent process.
