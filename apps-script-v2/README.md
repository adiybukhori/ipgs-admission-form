# Admission V2 Apps Script source

This directory is reserved for the Google Apps Script project `IUC_ADMISSION_BACKEND_V2_DEV` only.

Safety rules:

- V1 must never be stored or pushed from this directory.
- First sync must be `clasp pull` from the configured V2 Script ID.
- Do not use `clasp push --force`.
- Do not auto-deploy the Apps Script web app.
- Review Git diff before any future push.
- Keep production email mode disabled until separately approved.

The `.clasp.json` at repository root restricts clasp to this directory.
